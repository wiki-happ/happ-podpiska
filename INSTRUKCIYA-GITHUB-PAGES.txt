ЗАПУСК happ-podpiska.online НА GITHUB PAGES (аккаунт wiki-happ)

1. РЕПОЗИТОРИЙ
   github.com → «+» → New repository → имя: happ-podpiska → Public → Create (без галочки README).
   Add file → Upload files → перетащить ВСЁ содержимое папки site (включая CNAME и .nojekyll; на Маке скрытые файлы: Cmd+Shift+.) → Commit.

2. ВКЛЮЧИТЬ PAGES
   Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
   Ниже в Custom domain должно само подставиться happ-podpiska.online (из файла CNAME). Если пусто, вписать и Save.

3. DNS У РЕГИСТРАТОРА (Namecheap → Manage → Advanced DNS)
   Удалить существующие A/CNAME/URL-redirect записи для @ и www, добавить:
     A     @    185.199.108.153
     A     @    185.199.109.153
     A     @    185.199.110.153
     A     @    185.199.111.153
     CNAME www  wiki-happ.github.io.
   TTL любой. Обновление 10-60 минут.

4. HTTPS
   В Settings → Pages после появления DNS галочка «Enforce HTTPS» (может стать доступной через 15-30 минут). Поставить.

5. ПРОВЕРКА
   https://happ-podpiska.online/ и https://happ-podpiska.online/kupit открываются, стили есть, конфигуратор кликается.

6. МЕТРИКА
   Создать счётчик для happ-podpiska.online в общем аккаунте, получить номер, прислать мне: заменю METRIKA_ID во всех 8 файлах и отдам архив на перезаливку. Цели (JS): site_click, bot_click, sticky_click, cfg_pick, wizard_step, checklist_tick, key_check.

7. ВЕБМАСТЕР
   Добавить сайт, подтвердить через DNS-запись TXT (Namecheap → TXT record) или через файл (положить файл в репозиторий), отправить sitemap https://happ-podpiska.online/sitemap.xml, запустить переобход 7 страниц.

ОБНОВЛЕНИЯ: любой новый архив заливается так же, Upload files поверх → Commit; GitHub Pages пересобирает за минуту.
